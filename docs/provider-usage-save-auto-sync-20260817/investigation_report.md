# 供应商流量保存与自动同步调查报告

## 结论

流量读数无法保存包含两个已验证原因。前端数值输入限制为 0.001 GB 步进，供应商按字节换算后的多位小数无法通过浏览器原生校验。管理画面地址留空时，前端发送空字符串，后端的可选 URL 校验返回 422。

自动同步代码原先已经存在，运行条件和刷新频率未满足当前需求。只有支持的连接器且单机同步开关开启时才会进入调度，首次运行等待 30 秒，后续默认间隔 6 小时。页面每 60 秒拉取一次最新仪表盘数据。

## 修复

流量输入改为任意有效小数步进，套餐最小值调整为 1 字节对应的 0.000000001 GB。空管理地址在前后端统一转换为 null。后端保留按 1,000,000,000 换算并四舍五入为整数 byte 的现有存储边界。

OrangeVPS 与 Riven Cloud 根据供应商名称或后台域名选择连接器并默认启用同步。版本 6 migration 为已有完整认证档案识别连接器并开启同步。后台启动后立即执行，后续默认每 15 分钟执行一次。

## 风险

真实供应商网站登录未在本地验收中执行。连接器解析由已有 mock 测试覆盖。生产发布后应检查每台供应商档案的 last_sync_status、last_sync_message 和 last_synced_at。
# 首页同步新鲜度补充，2026-08-21

首页此前只展示读数采集时间，无法直接判断该读数是否来自最近一次成功的自动同步。流量卡现在返回自动同步状态、最后成功同步时间和相对时长。状态为“自动同步正常，15 分钟内已成功读取”时，表示供应商读取结果仍在 15 分钟窗口内。超过窗口、等待首次成功、同步失败、关闭自动同步和人工读数会分别显示，首页不再要求进入连接信息页判断。

## 多服务器自动同步核验，2026-08-21

后台同步任务按 `server_provider_access` 的全部记录筛选，不以首页卡片数量或第一台服务器为边界。入选条件为同步开关开启且连接器属于 OrangeVPS 或 Riven Cloud。新增回归测试同时放入两台合格服务器和一台关闭同步的服务器，断言前两台按 ID 顺序执行，关闭同步的记录不会执行。

## OrangeVPS 自动同步资格修正，2026-08-21

实际 OrangeVPS 请求仅用到后台账号、密码和服务编号。旧逻辑还要求外部服务器标识，导致这类档案显示为人工读数。版本 7 migration 为已有的三项完整 OrangeVPS 档案启用同步。Riven Cloud 仍要求外部服务器标识，因为其流量接口路径需要该 UUID。VMISS 目前没有已验证的官方流量读取接口或连接器，维持人工读数状态。
