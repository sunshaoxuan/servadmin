# 环境质量体检工具调查与实现报告

## 目标

为 Server Desk 增加按服务器手工触发的全面体检工具，并生成可审计的第二版“环境质量体检报告”。

## 现象复核

2026-07-30 读取 CCNODE-MAIN 的生产心跳样本后确认：

- 节点的配置检查状态为正常，心跳 Agent 本机应用分为 100。
- 相邻采样中出现过 `seen_by=["2"]`、传播 `0/7` 的仅自见状态。
- 下一采样恢复为 `seen_by=["13","2","4","7"]`、传播 `3/7`。
- 该现象属于短时传播证据不一致。单次 0/7 无法单独证明主机、应用或 SSH 整体故障。

## 原有能力边界

原“配置检查”可以收集操作系统、CPU、内存、磁盘、网络、软件包和监听端口。原环境评分主要判断字段是否成功采集，缺少资源阈值、失败服务、时间同步、SSH 策略、防火墙和心跳传播证据，无法形成完整的故障解释。

## 新工具行为

列表行和服务器详情均提供“全面体检”入口。每次体检顺序执行以下只读检查：

1. 使用服务器资料库中的登录方式执行 SSH 远程采集。
2. 采集系统资源、网络、服务、安全策略和应用清单。
3. 由主服务对启用心跳的节点读取签名报告。
4. 汇总最近 30 个分布式心跳样本的邻居确认率。
5. 生成六维度、总分 100 分的报告，并写入服务器现有环境报告字段。
6. 写入 `quality_check` 审计事件。

## 评分维度

| 维度 | 分值 | 主要证据 |
| --- | ---: | --- |
| 访问链路 | 15 | SSH 远程采集、登录资料完整性 |
| 系统资源 | 25 | 根分区、inode、内存、单核归一化负载、NTP |
| 网络质量 | 20 | 本机地址、默认路由、DNS、三个 HTTPS 出站目标 |
| 服务状态 | 15 | 失败的 systemd 服务、运行与监听服务清单 |
| 访问安全 | 15 | Root SSH、密码登录、主机防火墙 |
| 心跳传播 | 10 | Agent 签名直连、最新邻居确认、最近 30 个样本确认率 |

每个检查项保存状态、得分、满分、原始证据和修复建议。禁用分布式心跳的节点将该维度记录为信息项，不降低总分。

## 真实节点验证

在 CCNODE-MAIN 上执行新版只读采集，结果包括：

- 根分区使用率 14%，inode 使用率 3%。
- NTP 同步为 yes。
- 心跳服务和报告定时器均为 active。
- 主机防火墙为 active。
- Root 和密码 SSH 登录均为 yes，报告将其列为需要结合来源限制与防爆破措施核对的关注项。
- 发现 1 个失败服务：`snap.certbot.renew.service`。

真实节点首次验证还复现了 Windows 日文系统编码读取 UTF-8 SSH 输出失败的问题。远程检查现已固定使用 UTF-8 并对异常字节执行替换，回归测试覆盖该参数。

## 心跳强烈波动的后续调查

后续读取三小时生产证据后，已将原因定位到 CCNODE-MAIN 的主动上报调度：

- 主服务 165 个采集周期均为成功。
- 另外 7 台节点未出现未确认状态，CCNODE-MAIN 出现 86 次未确认和 76 次状态翻转。
- CCNODE-MAIN 的 Agent 监听服务持续 active，进程没有重启。
- 目标系统在 2026-07-27 发生过一次 boot。上一轮日志在 19:24:37 UTC 突然结束，新 boot 日志从 19:35:53 UTC 开始，没有正常 shutdown 序列。
- 主动上报定时器在新 boot 后进入 `active / elapsed`，最近触发停留在 19:23:42 UTC，下一次触发为空。
- 正常节点的同一定时器状态为 `active / waiting`，最近触发持续更新。

Agent 接收端仍能响应主服务和邻居请求。主服务直接读取 CCNODE 时获得最新的仅自见记录，邻居接收同一版本后会附加自身见证。多个报告源之间因此出现 0/7 与 1/7 至 5/7 的交替，形成强烈锯齿。

客机日志只能证明发生过一次缺少正常关机记录的重启。宿主机重启、硬复位、供电中断等来源需要供应商侧事件记录才能进一步区分。

全面体检已新增主动上报定时器状态、子状态、最近触发和下一次触发证据。`active / elapsed` 将按失败项处理。

## 风险

- 体检包含三个外部 HTTPS 探测，目标机严格限制出站时会显示失败。报告会保留目标与结果供人工判断。
- SSH 与防火墙策略采用只读有效配置。命令不可用时按信息项计分，并明确显示未采到指标。
- 心跳确认率取最近 30 个持久化样本，刚加入矩阵的节点可能样本不足。
